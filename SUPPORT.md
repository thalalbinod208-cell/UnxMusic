# Support

For help with UnX Music, please open a [GitHub issue](https://github.com/thalalbinod208-cell/UnxMusic/issues/new/choose) with:

- App version and Android version
- A short description of what happened
- Steps to reproduce the issue
- Expected and actual results

Remove passwords, cookies, tokens, email addresses, and other private details from screenshots and logs before posting. For security issues, follow [SECURITY.md](SECURITY.md) instead of posting exploit details publicly.

Release downloads and updates are listed on the [Releases page](https://github.com/thalalbinod208-cell/UnxMusic/releases).

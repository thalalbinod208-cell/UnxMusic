# Core source provenance

This directory vendors the `core` source used by the Unx Music build. It was supplied as the `core` Git submodule in the original SimpMusic tree (`https://github.com/maxrave-dev/core`). The current working tree includes the local modifications present when Unx Music 2.6.25 was packaged. The upstream submodule Git metadata is retained outside the public source tree in the local `.core-upstream-git-backup` directory and is not part of this repository. Keep the original license notices, including [`LICENSE`](LICENSE).

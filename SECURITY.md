# Security policy

## Reporting a vulnerability

Please use GitHub's [private vulnerability reporting](https://github.com/thalalbinod208-cell/UnxMusic/security/advisories/new) so a report is not exposed in a public issue. Include the affected version, impact, and reproduction details. Do not include real user credentials or private listening data.

If private reporting is unavailable, contact the maintainer through the [GitHub profile](https://github.com/thalalbinod208-cell) and share only enough information to arrange a private report.

## Supported versions

Security fixes are intended for the latest release. Older builds may not receive updates; use the [latest release](https://github.com/thalalbinod208-cell/UnxMusic/releases/latest).

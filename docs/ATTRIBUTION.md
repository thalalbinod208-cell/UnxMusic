# Visual asset attribution

This repository includes app screenshots and visual files supplied for the UnX Music project. Original attachment files were not changed; copies are organized under `assets/` and indexed in the [visual asset library](ASSET_LIBRARY.md).

UnX Music is based on [SimpMusic](https://github.com/maxrave-dev/SimpMusic). Some supplied concept boards and promotional references retain SimpMusic branding and upstream artwork. Their visible attribution is preserved. The feature-board gallery is reference material and is not a promise that every pictured screen or feature is in the current UnX Music release.

The source license does not automatically change the license of third-party artwork, album covers, logos, or media shown inside screenshots. Check the upstream notices and relevant rights before reusing those images outside this project.

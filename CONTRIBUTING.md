# Contributing to UnX Music

Thanks for taking an interest in the project.

## Before opening a pull request

1. Search existing issues and pull requests for the same problem.
2. For bugs, include the app version, Android version, reproduction steps, and expected versus actual behavior. Remove account details, tokens, and personal data from logs or screenshots.
3. Keep changes focused and preserve upstream SimpMusic attribution and license notices.
4. For code changes, run the relevant Gradle build or checks available for the module you changed, and include the result in the pull request.
5. Do not commit signing keys, API credentials, local machine files, or private user data.

## Licensing

Use the issue forms for [bug reports](https://github.com/thalalbinod208-cell/UnxMusic/issues/new?template=bug_report.yml) and [feature requests](https://github.com/thalalbinod208-cell/UnxMusic/issues/new?template=feature_request.yml).
